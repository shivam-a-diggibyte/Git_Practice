# Git_Practice

A training repository documenting daily Git and GitHub practice — commands, hands-on exercises, and screenshots captured while learning version control from the ground up.

## About This Repository

This repository is a personal learning log created during Git and GitHub training. Rather than a single project, it is a running record of exercises completed while practicing core Git concepts, commands, and collaboration workflows. Each entry reflects a hands-on task actually performed on the command line or on GitHub, along with supporting screenshots as evidence of the exercise.

The goal of this repository is to:

- Reinforce Git concepts through repetition and practice, not just reading.
- Keep a dated record of what was practiced and when.
- Serve as a personal reference to revisit specific commands or workflows later.

## Repository Structure

```
Git_Practice/
├── src/          # Practice exercises, command output, and screenshots, organized by topic/day
└── README.md     # Project overview (this file)
```

As training progresses, the `src/` folder is expected to grow with additional subfolders — for example, one per training day or per topic (basic commands, branching, merge conflicts, pull requests, and so on).

## Topics Covered

- **Git environment & workflow** — repository, working directory, staging area, and local repository; the modify → stage → commit cycle.
- **Fundamental commands** — `git init`, `git clone`, `git status`, `git add`, `git commit`, `git log`.
- **Branching & merging** — creating branches, feature branches, and merging changes back into `main`.
- **Merge conflicts & pull requests** — identifying and resolving conflicts; the branch → develop → PR → review → merge flow.
- **Git etiquette** — commit message conventions, one feature per branch, reviewing before merging, and avoiding committed secrets.

This list will expand as further topics are practiced and added to the repository.

## How to Use This Repository

Clone the repository to explore the exercises locally:

```bash
git clone https://github.com/shivam-a-diggibyte/Git_Practice.git
cd Git_Practice
```

Browse the `src/` folder for exercise notes, command output, and screenshots for each topic.

## Purpose

This repository was created as part of an ongoing training program to build practical, hands-on fluency with Git and GitHub. It is intended as a learning artifact and evidence of practice rather than a production codebase.
